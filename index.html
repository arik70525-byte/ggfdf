Управление проектами

Подключи репозиторий GitHub и токен с правом Contents: Read and write. Токен хранится только в памяти вкладки.

Не вставляй токен в публичные чаты и не сохраняй его в исходниках. Для безопасности создай отдельный токен только для этого репозитория.
